# 類似オーディエンスに絞り、Advantage+オーディエンスをオフにした広告セットが配信0になった

- 日付: 2026-09-26
- 種別: 調査
- 触れたファイル: なし(Meta広告セット 120252539068060028 のターゲティング設定のみ)

## 問題
トヨワクのテスト広告セット(Mechanic_Lead 最適化、日予算¥5,000)が、有効化から約12時間たっても
表示0件・費用¥0 のままだった。ステータスは ACTIVE、配信状態は `active / in_learning_phase` で、
エラーも審査落ちも出ていない。伊藤さんが別に作った「整備士狙い_ASC - 類似必須」も同じ症状だった。

## 文脈
- ステータスが ACTIVE なので、見た目では「配信中」に見える。前夜は「配信準備中なだけ」と判断し、
  半日見逃した。
- 同じキャンペーン(ASC)の他の広告セットは普通に費用を使っていたので、予算・支払い・キャンペーン側の
  問題ではない。

## 解法と、その理由
配信できたセットと配信0のセットで、ターゲティングを並べて差分を取った。
- 配信0の2セットの共通点: `custom_audiences` が類似1%のみ、`targeting_automation.advantage_audience=0`、
  `targeting_relaxation_types.lookalike=0`(類似を拡張しない)。
- 同じ類似オーディエンスを使っている AI動画のセットは `advantage_audience=1` で、普通に配信されていた。
- 類似オーディエンス自体を `ads_get_custom_audience` で見ると、`approximate_count` が 1000/1000。
  日本の1%類似として想定される規模(数十万〜百万程度)を大きく下回っていた。

→ 類似オーディエンスに絞り込んで拡張も禁止したため、配信対象がほぼ無い、と判断した。
修正は、類似オーディエンスを「提案」として残したまま `advantage_audience=1` にする方法を採った
(年齢上限は Advantage+ の要件に合わせて65歳に)。
類似の比率を広げる案(3〜5%)は、元の類似がそもそも小さいため効くか分からないので退けた。
伊藤さんのセットには手を出さず、Slack で共有した。

更新は `ads_update_entity` で「下書き」として保存されるだけで、公開には `ads_activate_entity`
(object_ids 指定)が必要だった。公開は須原さんの承認後に行った。

## うまくいかなかったこと
- 前夜の「配信準備中なので様子見」の判断。ACTIVE で表示0のまま数時間たったら、準備中ではなく
  配信対象が無い疑いを先に見るべきだった。

## 抽出したルール / ヒューリスティック
- 広告セットが ACTIVE なのに有効化から3時間以上表示0なら、「準備中」と決めつけず、まずターゲティングの
  絞り込み(`advantage_audience=0` かつカスタム/類似オーディエンス限定)と、オーディエンスの
  `approximate_count` を確認する。
- 類似オーディエンスで「固定」の比較テストを組むときは、作る前にオーディエンスの規模を確認する。
  規模が1000程度しか出ないなら、固定ではなく Advantage+ の提案として使う。
- `ads_update_entity` の結果が `is_draft: true` なら、まだ本番に反映されていない。
