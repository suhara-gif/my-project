# セットアップ手順

上から順に進めてください。手順1は Box の管理者、手順2は Anthropic の管理者、手順3以降は
Google Workspace の会社アカウントで作業します。画面の名称は各サービスの更新で変わることがあります。

## 0. 規程ファイルを「文字が入ったPDF」にそろえる

[README](../README.md) の「先に解消が必要なこと」を参照してください。スキャンした画像PDFのままでは、
アプリを公開しても就業規則について回答できません。

## 1. Box: 規程を読むためのアプリを作る

1. Box の開発者コンソール(https://app.box.com/developers/console)を開き、「アプリの新規作成」を選ぶ。
2. 「カスタムアプリ」→ 認証方法は「**サーバー認証(クライアント資格情報許可)**」を選ぶ。
   アプリ名は「社内規程Q&A」など。
3. 作成したアプリの「構成」タブで次を設定して保存する。
   - アプリアクセスレベル: **アプリアクセスのみ**
   - アプリケーションスコープ: **Boxに格納されているすべてのファイルとフォルダの読み取り**だけにチェック(書き込みは不要)
4. 「承認」タブからアプリを送信し、Box管理者が管理コンソール(「統合」→「Platformアプリマネージャー」)で承認する。
5. 「一般設定」タブに表示される**サービスアカウントのメールアドレス**(`AutomationUser_...@boxdevedition.com` の形式)を控える。
6. Box で `【共有】全社共通フォルダ/01_社内規程` を開き、手順5のメールアドレスを**ビューアー**として招待する。
   - 招待するのは規程フォルダだけにしてください。アプリが読めるのはこのフォルダだけになります。
7. 次の4つを控える(あとでスクリプトプロパティに入れます)。
   - クライアントID、クライアントシークレット(「構成」タブ)
   - Enterprise ID(「一般設定」タブ、または管理コンソールの「アカウント情報」)
   - 規程フォルダのID: フォルダを開いたときのURL `https://app.box.com/folder/【ここ】` の数字。
     2026-10-08 時点では `131041036361`

クライアントシークレットはパスワードと同じ扱いです。チャットやメールに貼らないでください。

## 2. Anthropic: APIキーを発行する

1. Anthropic Console(https://console.anthropic.com)にログインし、組織の支払い設定を済ませる。
2. 「API Keys」でキーを発行し、控える(このキーもパスワードと同じ扱い)。
3. 使いすぎを防ぐため、Console の「Limits」で月の利用上限を設定しておくことを推奨します。

## 3. Apps Script プロジェクトを作る

1. Google Drive で「新規」→「その他」→「Google Apps Script」を選び、名前を「社内規程Q&A」にする。
2. 左のファイル一覧で、次のファイルを作り、`kitei-qa/src/` 配下の同名ファイルの中身をそれぞれコピペする。

| Apps Scriptで作るファイル | 中身のコピー元 |
|---|---|
| `Code.gs`(最初からあるものを流用) | `src/Code.gs` |
| `Box.gs`(「+」→「スクリプト」) | `src/Box.gs` |
| `Claude.gs`(「+」→「スクリプト」) | `src/Claude.gs` |
| `Index.html`(「+」→「HTML」) | `src/Index.html` |

- ファイル名は拡張子を除いた部分(`Box` など)だけ入力すれば、Apps Scriptが自動で拡張子を付けます。
- 左の歯車アイコン(プロジェクトの設定)→「『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにし、
  `appsscript.json` の中身を `src/appsscript.json` に置き換える。

## 4. スクリプトプロパティを設定する

歯車アイコン(プロジェクトの設定)→「スクリプト プロパティ」に、次を追加して保存します。

| プロパティ | 値 |
|---|---|
| `BOX_CLIENT_ID` | 手順1-7のクライアントID |
| `BOX_CLIENT_SECRET` | 手順1-7のクライアントシークレット |
| `BOX_ENTERPRISE_ID` | 手順1-7のEnterprise ID |
| `BOX_FOLDER_ID` | 規程フォルダのID |
| `ANTHROPIC_API_KEY` | 手順2のAPIキー |
| `LOG_SHEET_ID`(任意) | 質問ログを残す場合だけ、記録先スプレッドシートのID。README「質問ログについて」を参照 |

スクリプトプロパティはプロジェクトの編集者なら誰でも見られます。編集者は管理担当者だけにしてください。

## 5. 読み込みを確認する

1. エディタ上部の関数選択で `checkSetup` を選び、「実行」を押す(初回は権限の承認画面が出るので許可する)。
2. 下の「実行ログ」に規程ファイルが1件ずつ表示されます。
   - `OK` のファイル: 回答に使われます
   - `NG` のファイル: 文字を読み取れません。文字が入ったPDFかWordに差し替えてください
3. 新しくアップロードした直後のファイルは、Box側のテキスト生成が終わっておらず `NG` になることがあります。
   数分おいてもう一度実行してください。

## 6. Webアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
2. 設定:
   - 次のユーザーとして実行: **自分**(従業員にBoxやAPIキーの権限を持たせないため)
   - アクセスできるユーザー: **(会社名)内の全員**
3. 「デプロイ」を押し、表示されたURLを従業員に共有する(社内ポータルやSlackのブックマークなど)。

## 規程を改定したとき

アプリ側の作業は不要です。

1. 新しい規程(文字が入ったPDFかWord)を規程フォルダの直下に置く。
2. 古い版を「旧フォルダ」へ移す。**直下に新旧両方が残っていると、両方を現行版として読んでしまいます。**
3. 念のため `checkSetup` を実行し、新しいファイルが `OK` になっているか確認する。

## コードを更新したとき

Apps Script のコードを貼り替えたら、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →
バージョン「新バージョン」で再デプロイしてください。URLは変わりません。
