# 社内規程Q&A

就業規則・給与規程などの社内規程について、従業員がふだんの言葉で質問できるWebアプリ。
質問のたびに Box の社内規程フォルダを読みに行くので、**規程を改定したら Box のファイルを
差し替えるだけで、回答も最新版に切り替わる。** NotebookLM のように新版を手作業で
アップロードし直す必要はない。

## できること

- 社内ドメインのGoogleアカウントでログインした従業員なら誰でも使える。
  Box アカウントやClaudeのアカウントは不要
- 回答には、根拠にした規程名と条番号、参照したファイルへのリンクが付く
- 区分(アプティ正社員/契約社員/アプティグローバル/派遣社員)を選ぶと、その区分の規程を優先して答える
- 規程に記載がないことは推測で答えず、人事・総務への確認を案内する
- 文字を読み取れないファイル(スキャン画像のPDF等)があると、画面に警告を出す

## 仕組み

```
従業員 ─(Googleログイン)→ GAS Webアプリ
                              ├─ Box API: 規程フォルダ「直下」のファイル一覧と本文テキストを取得
                              └─ Claude API: 規程本文 + 質問 → 回答
```

- **最新版の判定:** 規程フォルダ(Box: `【共有】全社共通フォルダ/01_社内規程`)の**直下にあるファイルを
  現行版とみなす。** サブフォルダ(「旧フォルダ」)の中は読まない。いまの運用(新版を直下に置き、
  旧版は旧フォルダへ移す)をそのまま使う。
- **本文の取得:** Box が自動生成するテキスト(extracted_text)を使う。ファイルのバージョンごとに
  6時間キャッシュし、Box側でファイルが更新されれば次の質問から読み直す。
- **Boxの認証:** Box のサーバー認証アプリ(Client Credentials Grant)を使う。アプリ専用の
  サービスアカウントを規程フォルダに「ビューアー」として招待するので、このアプリが読めるのは
  そのフォルダだけになる。

## 構成

```
kitei-qa/
├── src/
│   ├── Code.gs          画面の表示、質問の受付、規程の読み込み、ログ記録(任意)
│   ├── Box.gs           Box API(認証・フォルダ一覧・本文テキスト取得・キャッシュ)
│   ├── Claude.gs        Claude API 呼び出しとシステムプロンプト
│   ├── Index.html       質問画面
│   └── appsscript.json  マニフェスト(Webアプリをドメイン内限定で公開する設定)
└── docs/
    └── setup.md         セットアップ手順
```

## 技術選定の理由

- **Box AI を使わない理由:** 現在の Box 契約に Box AI が含まれていないため(須原さん確認済み)。
- **Claude の「スキル」+ Box コネクタにしない理由:** 従業員全員が Claude のアカウントを持っている
  必要があるが、持っていない従業員がいる(須原さん確認済み)。このアプリなら、Googleアカウントさえあれば使える。
- **GAS にした理由:** [`phone-manual-quiz/`](../phone-manual-quiz/) と同じく、Googleログインと
  ドメイン内限定公開が標準機能で済み、サーバーを別に用意しなくてよいため。

## 先に解消が必要なこと(2026-10-08 時点)

規程フォルダの就業規則本体が**複合機でスキャンした画像PDF**になっていて、文字データが入っていない。
見た目には本文があるが、プログラムからは文字として読めない。このままだと、就業規則についての
質問には答えられない(画面に「読み取れない規程」として警告が出る)。

| ファイル | 状態 |
|---|---|
| 株式会社アプティ_就業規則_20250401改定.pdf | 読めない(RICOH IM C3510 でスキャンした19ページの画像PDF。文字データ0文字) |
| 株式会社アプティグローバル_就業規則_20250301制定.pdf | 読めない(Box上で本文テキストが空) |
| 株式会社アプティ_給与規程.pdf | 読める |
| そのほかの規程 | 未確認。セットアップ後に `checkSetup` を実行すると一覧で確認できる |

**対策:** 元のWordファイル(または、Wordから書き出したPDF)を規程フォルダに置き、スキャン版は
旧フォルダへ移す。元ファイルが見つからない場合は、OCR(文字認識)をかけたPDFを置く。
ただしOCRは数字や日数を読み間違えることがあるので、置く前に人の目で確認すること。
今後の改定でも「**スキャンではなく、元データから書き出したPDFを置く**」ことを運用ルールにする。

## 前提・未確認事項

- 会社のGoogleアカウントが Google Workspace であること。[要確認]
- Box の契約プランで、カスタムアプリ(サーバー認証)を作成・承認できること。[要確認]
- 派遣社員など、会社のGoogleアカウントを持たない人は使えない。対象に含めたい場合は別の方法が必要。[要確認]
- 従業員は全員 Box のアカウントを持っている(須原さん確認済み)。ただし回答画面のファイルへのリンクは、
  Box上で規程フォルダの閲覧権限がある人しか開けない。全員に閲覧権限があるかは [要確認]。
  回答自体は、Boxの権限に関係なく全員が見られる。就業規則は従業員への周知義務があるため、
  全員に見せて問題ないという前提。ただし、フォルダに周知対象外の文書を置くと、その内容も
  回答に使われる点に注意。
- **費用 [要確認]:** Claude API の従量課金。規程の総量が実測できていないため、仮定に基づく試算に留める。
  - 仮定: 規程全体で約5万トークン(日本語で7〜10万字程度)、回答1件あたり出力2千トークン
  - Claude Opus 5.5(入力 $4 / 出力 $20 / 100万トークンあたり)の場合、1問あたり約 $0.3(約45円)
  - 5分以内に続けて質問が来た場合は、規程部分がキャッシュされ1問あたり約 $0.05 になる
  - 規程を読めるようにしたあと、実際の使用量(Anthropic Console の Usage)で確認すること
- **応答時間 [要確認]:** GAS から外部APIを呼ぶときの待ち時間には上限がある。規程の量が多いと
  回答に時間がかかり、タイムアウトする可能性がある。発生した場合は `src/Claude.gs` の
  `CLAUDE_EFFORT` を `'low'` に下げる。

## 質問ログについて

既定では質問内容を記録しない。退職・育休・懲戒など、人に知られたくない質問もありうるため。
よくある質問を把握したい場合は、スクリプトプロパティ `LOG_SHEET_ID` にスプレッドシートIDを
設定すると、日時・区分・質問文を記録する(メールアドレスは記録しない)。記録する場合は、
画面上でその旨を従業員に告知すること。
