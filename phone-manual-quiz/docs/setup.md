# セットアップ手順(コピペで完結)

プログラミング不要です。上から順にやってください。所要目安10分。

## 前提

- 会社のGoogle Workspaceアカウント(@あなたの会社ドメイン)でログインしていること。
- 個人のGmail(@gmail.com)ではドメイン内限定公開が使えないため、必ず会社アカウントで作業してください。[要確認: 会社アカウントがGoogle Workspace契約であること]

## 1. 結果を記録するスプレッドシートを作る

1. Google Driveで新規スプレッドシートを作成し、名前を「電話コミュニケーション理解度テスト_結果」などにする。
2. URLの `https://docs.google.com/spreadsheets/d/【ここがID】/edit` の【ここがID】部分をコピーしてメモしておく(あとで使います)。

## 2. Apps Script プロジェクトを作る

1. 手順1で作ったスプレッドシートを開いた状態で、メニュー「拡張機能」→「Apps Script」を開く。
   - これで、このスプレッドシートに紐づいたスクリプトプロジェクトができます。
2. 最初から入っている `コード.gs` の中身は全部消してよい。

## 3. このリポジトリのコードを貼り付ける

Apps Script エディタで、左の「ファイル」から次の3つを作成し、`phone-manual-quiz/src/` 配下の同名ファイルの中身をそれぞれコピペする。

| Apps Scriptで作るファイル | 中身のコピー元 |
|---|---|
| `Code.gs`(最初からあるものを流用可) | `src/Code.gs` |
| `Questions.gs`(スクリプトファイルとして新規追加) | `src/Questions.gs` |
| `Index.html`(HTMLファイルとして新規追加) | `src/Index.html` |

- 新規ファイルの追加は、ファイル一覧の「+」→「スクリプト」または「HTML」から。
- ファイル名は拡張子を除いた部分(`Code`、`Questions`、`Index`)だけ入力すればOK(Apps Scriptが自動で `.gs`/`.html` を付ける)。
- `appsscript.json` は通常エディタの左下の歯車アイコン→「マニフェスト ファイルを表示」を有効にすると編集できます。`src/appsscript.json` の中身に置き換えてください(既存の内容を残しつつ `webapp` の部分だけ追記でも可)。

## 4. スプレッドシートIDを設定する

1. Apps Script エディタ左メニューの歯車アイコン(プロジェクトの設定)を開く。
2. 「スクリプト プロパティ」→「スクリプト プロパティを追加」。
3. プロパティ: `RESULTS_SHEET_ID`、値: 手順1でメモしたスプレッドシートIDを入力して保存。

## 5. Webアプリとして公開する

1. エディタ右上「デプロイ」→「新しいデプロイ」。
2. 種類の選択(歯車アイコン)で「ウェブアプリ」を選ぶ。
3. 設定:
   - 説明: 任意(例: 初回公開)
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **〇〇(組織名)内のユーザー** ※ドメイン内限定になっているか必ず確認
4. 「デプロイ」をクリックし、初回は権限の承認画面が出るので許可する。
5. 発行された「ウェブアプリのURL」が受験用URL。これを社内に案内する。

- アクセス設定が「全員」になっていると社外の人でも回答できてしまうので注意。
- コードを修正した後は、「デプロイ」→「デプロイを管理」→編集(鉛筆アイコン)→バージョンを「新バージョン」にして更新、で同じURLのまま反映されます。

## 6. 結果シートを社内に公開する(閲覧のみ)

手順1のスプレッドシートを開き、「共有」→「〇〇(組織名)内で共有」→権限を「閲覧者」にする。
編集権限を配ると誰でも点数を書き換えられてしまうため、社内共有は必ず閲覧者権限にすること。

## 7. 動作確認

1. 発行されたURLに自分のブラウザでアクセスし、1回テストを受けてみる。
2. スプレッドシートの `results` シートに1行(日時・メールアドレス・点数・合否・誤答問題ID・誤答した章・フィードバック)が追加されていることを確認する。

## 問題を追加・修正したいとき

`src/Questions.gs` の配列に問題オブジェクトを追加/編集し、Apps Scriptエディタ側の `Questions.gs` に反映して再デプロイするだけです。`id` は他の問題と重複しないようにしてください。
