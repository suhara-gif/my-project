# 電話コミュニケーション理解度テスト

「電話コミュニケーション基本マニュアル」(全員向け)と「基本FBチェックシート」(RA向け)を
社内に配ったあと、内容が身についたかを測定するためのテストアプリ。

## できること

- Googleアカウント(会社ドメイン限定)でログインして受験
- 4択×20問、100点満点・90点以上で合格(`src/Code.gs` の `PASS_SCORE` で変更可)
- 正解はサーバ側でのみ判定し、クライアントには渡さない
- 受験ごとに結果をスプレッドシートへ1行記録(日時・メールアドレス・点数・合否・誤答問題ID・誤答した章)
- 誤答した問題の章をもとに、その場で復習アドバイスを表示

## 構成

```
phone-manual-quiz/
├── src/
│   ├── Code.gs          サーバ側ロジック(採点・記録・フィードバック生成)
│   ├── Questions.gs      問題データ(20問。追加・修正はここを編集するだけ)
│   ├── Index.html        受験画面(HTML/CSS/JS)
│   └── appsscript.json   マニフェスト(Webアプリをドメイン内限定公開する設定)
└── docs/
    └── setup.md          非エンジニア向けセットアップ手順(コピペで完結)
```

## 技術選定の理由

Google Apps Script(GAS)で実装。Googleアカウントでのログインとスプレッドシートへの
書き込みがどちらもネイティブ機能で完結し、外部ホスティングやサービスアカウントの
秘密鍵管理が不要なため。Next.js等の別アプリで作る場合と比べ、この規模の社内テストには
運用コストが小さい。

## セットアップ

`docs/setup.md` を参照。Apps Scriptエディタへのコピペとスプレッドシート共有設定だけで
公開できます(このリポジトリからの自動デプロイは行っていません)。

## 前提・未確認事項

- 会社アカウントがGoogle Workspace契約であること(個人Gmailだとドメイン内限定公開ができません)。[要確認]
- Web Appのドメイン内限定公開・スクリプト実行が組織のGoogle Workspace管理者ポリシーで
  制限されていないこと。[要確認]
- 出題範囲は今回渡された2資料([①電話コミュニケーション基本マニュアル 全員向け]と
  [④電話コミュニケーション基本FBチェックシート RA向け])のみ。ファイル名の連番から
  ②③⑤などCA/CM向けの資料が別途存在する可能性があるが、今回は対象外。

## 今後の拡張

- 他資料(②③⑤等)が届いたら `src/Questions.gs` に問題を追加するだけで拡張可能。
- 合格基準・満点構成を変えたい場合は `src/Code.gs` の `PASS_SCORE` と、問題数(100点を
  問題数で割った配点)を調整する。
